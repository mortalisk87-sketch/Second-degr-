# Le second degré – Révisions de Seconde

Application web de révision sur les trinômes du second degré (programme de Seconde), en un seul fichier HTML sans dépendance (hors police Google Fonts facultative).

## Contenu
- **Leçon** : forme canonique, extremum et tableau de variation, représentation graphique, équation avec le discriminant Δ, factorisation, signe du trinôme (tableaux de signe et graphiques)
- **Explorateur** : saisie de a, b, c et étude complète du trinôme
- **Exercices** : énoncés aléatoires, vérification et correction détaillée
- **QCM** : 12 questions avec explications
- **Contrôle** : 7 exercices sur 20 points, chronométré (30 min)

## Utilisation
Ouvrir `index.html` dans un navigateur.

## Publier sur GitHub Pages
1. Créer un dépôt GitHub et y déposer `index.html` et `README.md`.
2. Aller dans **Settings → Pages**.
3. Choisir la branche `main` et le dossier `/ (root)`, puis **Save**.
4. Le site sera disponible sur `https://<ton-pseudo>.github.io/<nom-du-depot>/`.
